# 可信心理健康知识问答系统（Trustworthy RAG）

医疗 / 心理领域的知识问答，最大的风险不是「答不出」，而是「**没有依据也编得像真的**」。
本项目把 RAG 做成 **可溯源、可拒答、可评估**：

- **有据必引**：回答里每一句都带引用标记，可追到原文片段（来源 + 页码 / 章节）
- **无据必拒**：检索不到依据时明确拒答，而不是让模型硬编
- **可评估**：用带标注的评测集量化「检索命中 / 引用覆盖率 / 支撑率 / 拒答正确率」

> 与另一个项目《多智能体求职陪练 Agent》的分工：那个主打**编排与工程可靠性**（工具契约、状态机、降级链、注入防护、人机确认闸门）；本项目主打**知识质量与可信性**（切分、检索、重排、引用、拒答）。两者不重叠。

## 关键问题与设计取舍

| 环节 | 常见做法（本项目不用） | 本项目做法（为什么） |
| --- | --- | --- |
| 切分 | 定长按字符硬切 | **结构感知**：按章节 / 条目切，块带「来源 + 页码 + 章节」元数据 —— 定长常切出半句话，且无从引用 |
| 检索 | 单路稠密 or 单路稀疏 | **稠密(BGE-M3) + 稀疏(BM25) + RRF 融合**，再 BGE-Reranker 重排 —— 医学名词、药名靠稀疏；语义相近靠稠密 |
| 生成 | 只给上下文，任其发挥 | **逐句引用**：每句必须以 [n] 结尾；检索不到就输出「无依据」 |
| 幻觉 | 无视 or 正则删文本 | **句级引用校验 + 拒答闸门**：逐句核查引用是否被上下文支撑，支撑率过低则不回答 |
| 评测 | 相似度阈值当「命中」 | **带标注评测集**（可答 + 应拒答），分别量化检索与生成、以及「该拒的拒了吗」 |

## 架构

```
数据层  →  检索层  →  生成层  →  评测层
```

1. **数据层**
   - 语料：权威中文指南（抑郁症基层诊疗指南 2021、抑郁障碍治疗与管理专家推荐意见 2022、
     精神障碍诊疗规范 2020 的抑郁相关章节）+ 患者向科普（默沙东诊疗手册大众版、WHO 中文）
   - 先做**数据质量验证**：对每本文档量化「对目标患者问题的覆盖率」，据此决定留 / 剔 / 补
   - **结构感知切分**：按章节 / 条目切分，块携带 `source / page / heading` 元数据
2. **检索层**
   - 稠密向量 BGE-M3 · 稀疏 BM25(jieba) · **RRF 融合** · BGE-Reranker 重排
   - 查询改写（同义 / 拆解多查询）+ 上下文压缩（只留与问题最相关的句子，降噪）
3. **生成层（可信机制，本项目核心）**
   - 逐句引用 prompt（每句带 [n]，无依据只输出「无依据」）
   - **句级引用校验**：逐句判定「引用到的那段资料是否真的支撑这句话」（支撑率）
   - **拒答闸门**：检索相关度低于阈值、或支撑率过低 → 拒答而不是硬答
4. **评测层**
   - 有标注集：可答问题（带期望要点）+ 应拒答问题（知识库确实没有）
   - 指标：检索命中 / top1 命中 · 引用覆盖率 · 支撑率 · 拒答正确率

## 评测结果

有标注集：**15 个可答问题 + 6 个应拒答问题**（`data/eval_set.json`）

| 指标 | 结果 | 口径 |
| --- | --- | --- |
| 检索命中 | 15/15 | 期望要点落在 top-6 检索片段内 |
| top1 命中 | 14/15 | 期望要点落在首位 |
| **拒答正确率** | **6/6** | 知识库确实没有依据时，系统明确拒答 |
| 误拒 | 0/15 | 有依据的问题被误判成无依据 |
| 引用覆盖率 | 0.85 | 回答中含引用标记的句子占比 |
| 支撑率 | 0.91 | 被引用的句子确有资料支撑的占比 |

复现：`python rag/run_eval.py`（结果写 `results_eval.json`）

## 快速开始

```bash
# 1. 建索引（bge-m3 稠密 + BM25，读 data/kb_clean/chunks.jsonl）
python -c "import sys; sys.path.insert(0,'.'); from rag import engine; engine.init()"

# 2. 命令行提问
python rag/cli.py "吃抗抑郁药会上瘾吗？"

# 3. 跑评测
python rag/run_eval.py
```

## 局限与边界（诚实声明）

- 语料规模有限（中文权威内容约数十万字），部分细粒度用药问题依据不足，系统会拒答而非猜测
- 拒答闸门偏严：会带来少量**误拒**（宁可不答，不可乱答的取舍）
- 支撑判定为**机器判定**，需人工抽检；评测集规模有限，是首版口径
- 不做诊断、不开处方、不替代就医；涉及自伤 / 自杀风险时提示寻求专业帮助
